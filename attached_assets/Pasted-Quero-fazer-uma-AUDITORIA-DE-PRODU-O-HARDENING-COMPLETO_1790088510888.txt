3. TESTE CRÍTICO: APP FECHADO
==================================================

Esse é um dos testes mais importantes.

Simule:

- usuário autorizado;
- localização conhecida;
- push token registrado;
- aplicativo completamente fechado.

DISPOSITIVO B:

- fornece latitude/longitude;
- dispara rescue fanout.

-> rescue_fanout_state
-> seleção geográfica
-> notification event
-> push job
-> worker
-> FCM/APNs
-> dispositivo A
-> notificação recebida
-> deep link correto
-> abertura do rescue correto.
