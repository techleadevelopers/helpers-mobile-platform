4. FOLLOW / UNFOLLOW — AUDITORIA OBRIGATÓRIA
============================================

"Seguir" é uma relação GLOBAL do usuário.

Não deve existir uma regra diferente para cada tela.

Verificar todos os pontos existentes onde Follow/Unfollow aparece:

* Feed;
* Post/Card;
* Users;
* Search;
* Profile;
* Followers;
* Following;
* recomendações;
* qualquer outro componente.

Se A segue B em qualquer lugar:

A -> B = FOLLOWING

Todas as telas devem reconhecer a mesma relação.

Auditar:

* endpoint;
* service;
* banco;
* unique constraint;
* concorrência;
* contadores;
* cache;
* estado local;
* optimistic update;
* rollback;
* refetch;
* invalidação;
* persistência após logout/login.

Testar:

Follow pelo Feed → verificar Users/Profile.

Follow pelo Users → verificar Feed/Profile.

Unfollow pelo Profile → verificar Feed/Users.

Duplo clique → não duplicar.

Requests simultâneos → não duplicar.

Falha de API → UI não pode ficar em estado falso.

Outro usuário C → não pode enxergar A como seguidor de B.

==========================
